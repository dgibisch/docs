---
title: "Claude app"
description: "Connect the Claude app to everydeck as a custom connector and run the setup in a Code session on the repository of your app."
---

In the Claude app, everydeck is a custom connector. It works in chat, in Cowork and in the Code tab. The setup itself runs in the Code tab.

On the setup page, **Claude app** means claude.ai, the desktop app or Claude Code on the web, also when it works on GitHub in the cloud. It is the first choice on the page.

## Connect

<Steps>
  <Step title="Add the connector">
    In the Claude app, open **Settings**, then **Connectors**, and click **Add custom connector**. Name it `everydeck`, paste the address `https://app.everydeck.ai/mcp` (also shown on the setup page) and click **Add**.
  </Step>
  <Step title="Sign in">
    Click **Connect**, then **Allow**.
  </Step>
  <Step title="Pick the model">
    Choose Opus 5.5 with effort Medium or higher in the model menu before you paste. everydeck was tested with it. A smaller model or a lower effort may leave parts out or stop halfway; everydeck shows you what is still open.
  </Step>
  <Step title="Paste the sentence in the Code tab">
    The setup page says **Paste this into the Code tab of the Claude app**. Open a Code session on the repository of your app, in the cloud or on your computer. Paste the sentence from the setup page. That is the last thing you type.
  </Step>
</Steps>
