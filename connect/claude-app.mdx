title: "Claude app"
description: "Connect the Claude app to everydeck as a custom connector and run the setup in the Code tab on the folder of your app."
---

In the Claude app, everydeck is a custom connector. It works in chat, in Cowork and in the Code tab. The setup itself runs in the Code tab.

## Connect

<Steps>
  <Step title="Add the connector">
    In the Claude app, open **Settings**, then **Connectors**, and click **Add custom connector**. Name it `everydeck`, paste the address `https://app.everydeck.ai/mcp` (also shown on the setup page) and click **Add**.
  </Step>
  <Step title="Sign in">
    Click **Connect**, then **Allow**.
  </Step>
  <Step title="Paste the sentence in the Code tab">
    Open the Code tab on the folder of your app. Paste the sentence from the setup page. That is the last thing you type.
  </Step>
</Steps>

No model was measured with the Claude app, so the setup page gives no model note for it. everydeck shows you what is still open after the setup.
